### Types of datatypes

- Primitive Data Types = int, char, float, double, void
- Derived Data Type = array, pointer, function
        Mainly defined by the help of primitive datatypes
- User Defined Data Type = structure, union, enum

### ESCAPE SEQUENCE

- \t        tab
- \n        New Line
- \b        Backspace
- \'        Single quotes
- \\        Backslash
- %%        Percentage
